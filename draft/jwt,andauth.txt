```tsx
ঠিক আছে, তুমি ব্যাকএন্ডে `jsonwebtoken` (JWT) দিয়ে অথেনটিকেশন হ্যান্ডেল করছ এবং টোকেন রেসপন্সে পাঠাচ্ছ। ফ্রন্টএন্ডে তুমি `next-auth` ব্যবহার করতে চাও, কিন্তু উদ্বেগ আছে যে ব্যাকএন্ডে একটা অথেনটিকেশন সিস্টেম (JWT) এবং ফ্রন্টএন্ডে আরেকটা (`next-auth`) ব্যবহার করলে জটিলতা হতে পারে। তুমি এও বলেছ যে তোমার ওয়েবসাইটে শুধু তুমি একজন ইউজার হিসেবে থাকবে এবং লগইন পেজ শুধু তোমার জন্য। আমি এখন ধাপে ধাপে ব্যাখ্যা করব কীভাবে তুমি ফ্রন্টএন্ডে `next-auth` ব্যবহার করে ব্যাকএন্ডের JWT-ভিত্তিক অথেনটিকেশনের সাথে ইন্টিগ্রেট করতে পারো এবং কীভাবে 
টোকেন হ্যান্ডেল করবে।

---

### **তোমার ব্যাকএন্ড সেটআপ**
তোমার দেওয়া কোড থেকে বুঝতে পারছি:
1. **লগইন প্রক্রিয়া** (`auth.controller.ts`):
   - `login` ফাংশনে ইউজারের ইমেইল এবং পাসওয়ার্ড ভ্যালিডেট করা হচ্ছে।
   - সফল লগইনের পর একটা JWT টোকেন জেনারেট করা হচ্ছে (`jwt.sign`) এবং রেসপন্সে পাঠানো হচ্ছে:
     ```json
     {
       "success": true,
       "message": "owner logged successfully",
       "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
       "data": { ...userWithoutPassword }
     }
     ```
   - টোকেনে `userId`, `role`, এবং `email` এনকোড করা হচ্ছে।

2. **অথেনটিকেশন মিডলওয়্যার** (`authMiddleware.ts`):
   - `authenticate` মিডলওয়্যারে টোকেন চেক করা হচ্ছে:
     - প্রথমে `Authorization` হেডার থেকে `Bearer <token>` ফরম্যাটে টোকেন নেওয়া হচ্ছে।
     - যদি হেডারে না থাকে, তাহলে `req.cookies.token` থেকে টোকেন নেওয়া হচ্ছে।
   - টোকেন ভ্যালিড হলে `jwt.verify` দিয়ে ডিকোড করে `req.user`-এ সেট করা হচ্ছে।
   - `isAdmin` মিডলওয়্যার চেক করে ইউজারের `role` যদি `owner` না হয়, তাহলে 403 ফেরত দেয়।

3. **সীড ফাংশন** (`seed.ts`):
   - একটা অ্যাডমিন ইউজার তৈরি করা হচ্ছে (`role: 'owner'`)। এটা মানে তুমি শুধু এই ইউজার দিয়ে লগইন করবে।

4. **ভ্যালিডেটর** (`validator.ts`):
   - `ValidateRequestByZod_mid_higherFunc` দিয়ে লগইনের ডেটা ভ্যালিডেট করা হচ্ছে।

### **তোমার উদ্বেগ: ব্যাকএন্ডে JWT এবং ফ্রন্টএন্ডে Next-Auth**
তুমি চিন্তিত যে ব্যাকএন্ডে JWT এবং ফ্রন্টএন্ডে `next-auth` ব্যবহার করলে জটিলতা হবে। এটা আসলে কোনো সমস্যা না, যদি তুমি সঠিকভাবে ইন্টিগ্রেশন করো। `next-auth` এর সাথে কাস্টম ক্রিডেনশিয়াল প্রোভাইডার ব্যবহার করে তোমার ব্যাকএন্ডের `/login` এন্ডপয়েন্টের সাথে কানেক্ট করা যায়। এতে:
- ফ্রন্টএন্ডে `next-auth` টোকেন ম্যানেজ করবে (কুকিতে সেট করবে, সেশন হ্যান্ডেল করবে)।
- ব্যাকএন্ডে তোমার JWT-ভিত্তিক অথেনটিকেশন অপরিবর্তিত থাকবে।

তুমি যেহেতু বলেছ যে শুধু তুমি একজন ইউজার হিসেবে থাকবে, তাই `next-auth` এর কনফিগারেশন খুবই সিম্পল হবে।

#### **ধাপ ১: Next-Auth ইনস্টল করো**

#### **ধাপ ২: Next-Auth কনফিগার করো**
Next.js প্রজেক্টে `app/api/auth/[...nextauth]/route.ts` ফাইল তৈরি করো এবং নিচের কোড যোগ করো:

```typescript
import NextAuth, { NextAuthOptions } from "next-auth";
import CredentialsProvider from "next-auth/providers/credentials";

export const authOptions: NextAuthOptions = {
  providers: [
    CredentialsProvider({
      name: "Credentials",
      credentials: {
        email: { label: "Email", type: "email" },
        password: { label: "Password", type: "password" },
      },
      async authorize(credentials) {
        if (!credentials?.email || !credentials?.password) {
          throw new Error("Email and password are required");
        }

        // ব্যাকএন্ডের /login এন্ডপয়েন্টে রিকোয়েস্ট পাঠানো
        const res = await fetch(
          `${process.env.NEXT_PUBLIC_BASE_URL}/auth/login`,
          {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({
              email: credentials.email,
              password: credentials.password,
            }),
          }
        );

        const result = await res.json();

        if (res.ok && result.success) {
          // ব্যাকএন্ড থেকে টোকেন এবং ইউজার ডেটা পাওয়া গেছে
          return {
            id: result.data.id,
            name: result.data.name,
            email: result.data.email,
            role: result.data.role,
            token: result.token, // JWT টোকেন
          };
        } else {
          throw new Error(result.message || "Login failed");
        }
      },
    }),
  ],
  callbacks: {
    async jwt({ token, user }) {
      // প্রথম লগইনের সময় ইউজার ডেটা টোকেনে যোগ করো
      if (user) {
        token.id = user.id;
        token.role = user.role;
        token.accessToken = user.token; // ব্যাকএন্ডের JWT টোকেন
      }
      return token;
    },
    async session({ session, token }) {
      // সেশনে ইউজার ডেটা এবং টোকেন যোগ করো
      session.user.id = token.id as number;
      session.user.role = token.role as string;
      session.accessToken = token.accessToken as string;
      return session;
    },
  },
  pages: {
    signIn: "/login", // কাস্টম লগইন পেজ
  },
  session: {
    strategy: "jwt", // JWT-ভিত্তিক সেশন
  },
  secret: process.env.NEXTAUTH_SECRET, // .env ফাইলে সেট করতে হবে
};

export default NextAuth(authOptions);
```

**ব্যাখ্যা**:
- **CredentialsProvider**: এটা ব্যাকএন্ডের `/auth/login` এন্ডপয়েন্টে ইমেইল এবং পাসওয়ার্ড পাঠায়। ব্যাকএন্ড থেকে সফল রেসপন্স পেলে ইউজার ডেটা এবং টোকেন রিটার্ন করে।
- **callbacks**: 
  - `jwt` কলব্যাক টোকেনে ইউজারের `id`, `role`, এবং `accessToken` (ব্যাকএন্ডের JWT) যোগ করে।
  - `session` কলব্যাক সেশনে এই ডেটাগুলো সেট করে, যাতে ফ্রন্টএন্ডে `useSession` দিয়ে এগুলো অ্যাক্সেস করা যায়।
- **pages**: কাস্টম লগইন পেজ `/login` পাথে সেট করা হয়েছে।
- **session.strategy**: `jwt` সেট করা হয়েছে, কারণ তুমি ব্যাকএন্ড থেকে JWT ব্যবহার করছ।

**.env ফাইলে যোগ করো**:
```env
NEXTAUTH_SECRET=your_nextauth_secret_here
NEXT_PUBLIC_BASE_URL=http://your-backend-url
```

`NEXTAUTH_SECRET` তৈরি করতে পারো এভাবে:
```bash
openssl rand -base64 32
```

          <label htmlFor="email" className="block text-sm font-medium mb-1">
            Email
          </label>
          <input
            type="email"
            id="email"
            value={email}
            onChange={(e) => setEmail(e.target.value)}
            className="w-full rounded-md border px-3 py-2"

          type="submit"

- সফল লগইন হলে ইউজারকে `/blogs` পেজে রিডাইরেক্ট করা হয়।

#### **ধাপ ৪: টোকেন হ্যান্ডলিং ফ্রন্টএন্ডে**
`next-auth` স্বয়ংক্রিয়ভাবে টোকেন কুকিতে সেট করে এবং সেশন ম্যানেজ করে। তুমি ফ্রন্টএন্ডে `useSession` হুক বা `getServerSession` ব্যবহার করে সেশন ডেটা অ্যাক্সেস করতে পারো। উদাহরণ:

**ক্লায়েন্ট-সাইডে**:
```typescript
"use client";
import { useSession } from "next-auth/react";

export default function ProtectedPage() {

  if (!session) return <p>Please log in</p>;

  return (
    <div>
      <h1>Welcome, {session.user.name}</h1>
      <p>Role: {session.user.role}</p>
      <p>Access Token: {session.accessToken}</p>
    </div>
  );
}
```

**সার্ভার-সাইডে**:
```typescript
import { getServerSession } from "next-auth";

export default async function ServerProtectedPage() {

#### **ধাপ ৫: ব্যাকএন্ডে টোকেন হ্যান্ডলিং**
তোমার ব্যাকএন্ডে ইতিমধ্যে `authenticate` মিডলওয়্যার আছে, যেটা:
- `Authorization: Bearer <token>` হেডার থেকে টোকেন নেয়।
- অথবা কুকি থেকে `req.cookies.token` নেয়।
- `jwt.verify` দিয়ে টোকেন ভ্যালিডেট করে এবং `req.user`-এ ইউজার ডেটা সেট করে।

**সমস্যা**: তুমি ব্যাকএন্ডে কুকিতে টোকেন সেট করছ না, শুধু রেসপন্সে পাঠাচ্ছ। `next-auth` কুকিতে নিজস্ব সেশন টোকেন সেট করে, তাই ব্যাকএন্ডের `req.cookies.token` চেক করা কাজ নাও করতে পারে। এর জন্য:
- ফ্রন্টএন্ড থেকে সবসময় `Authorization` হেডারে টোকেন পাঠাও (`session.accessToken` ব্যবহার করে)।
- ব্যাকএন্ডে `req.cookies.token` চেক করার লজিক বাদ দিতে পারো, যেহেতু তুমি কুকিতে টোকেন সেট করছ না।

**মডিফাইড `authMiddleware.ts`**:
```typescript
import { NextFunction, Request, Response } from "express";
import jwt from "jsonwebtoken";
import { envVars } from "./../config/env.config";

export const authenticate = (req: Request, res: Response, next: NextFunction) => {
  const authHeader = req.headers.authorization;

  if (!authHeader || !authHeader.startsWith("Bearer ")) {
    return res.status(401).json({ success: false, message: "No token provided" });
  }

  const token = authHeader.split(" ")[1];

  try {
    const decoded = jwt.verify(token, envVars.JWT_ACCESS_TOKEN_SECRET!) as {
      userId: number;
      role: string;
    };
    req.user = decoded;
    next();
  } catch (error) {
    return res.status(401).json({ success: false, message: "Invalid token" });
  }
};

export const isAdmin = (req: Request, res: Response, next: NextFunction) => {
  if (req.user?.role !== "owner") {
    return res.status(403).json({ success: false, message: "Forbidden, you are not owner." });
  }
  next();
};
```

#### **ধাপ ৬: শুধু একজন ইউজার হওয়ার সুবিধা**
তুমি যেহেতু বলেছ যে শুধু তুমি একজন ইউজার হিসেবে থাকবে:
- `next-auth` কনফিগারেশন খুবই সিম্পল রাখতে পারো। শুধু ক্রিডেনশিয়াল প্রোভাইডার ব্যবহার করলেই হবে।
- লগইন পেজে শুধু তোমার জন্য ইমেইল এবং পাসওয়ার্ড ইনপুট থাকবে।
- প্রোটেক্টেড রুটগুলোতে (যেমন: `/blogs`) চেক করো যে সেশন আছে এবং `role` হচ্ছে `owner`।

**প্রোটেক্টেড রুটের উদাহরণ**:
```typescript
import { getServerSession } from "next-auth";
import { authOptions } from "@/app/api/auth/[...nextauth]/route";
import { redirect } from "next/navigation";

export default async function BlogsPage() {
  const session = await getServerSession(authOptions);

  if (!session || session.user.role !== "owner") {
    redirect("/login");
  }

  return <div>Protected Blogs Page</div>;
}

#### **ধাপ ৭: টেস্টিং টিপস**
1. **লগইন টেস্ট**:
   - `/login` পেজে গিয়ে ইমেইল এবং পাসওয়ার্ড দিয়ে লগইন করো।
   - `console.log(session)` দিয়ে চেক করো সেশনে `accessToken`, `id`, `role` ইত্যাদি সঠিকভাবে সেট হচ্ছে কিনা।

2. **API কল টেস্ট**:
   - ব্লগ তৈরির সময় `session.accessToken` ব্যবহার করে `Authorization` হেডারে টোকেন পাঠাও।
   - ব্যাকএন্ডে `console.log(req.user)` দিয়ে চেক করো টোকেন ডিকোড হচ্ছে কিনা।

3. **কুকি চেক**:
   - ব্রাউজারের ডেভ টুলে (Application > Cookies) চেক করো `next-auth.session-token` সেট হচ্ছে কিনা।

#### **শেষ কথা**
- ব্যাকএন্ডে JWT এবং ফ্রন্টএন্ডে `next-auth` একসাথে ব্যবহার করা কোনো সমস্যা না। `next-auth` এর ক্রিডেনশিয়াল প্রোভাইডার ব্যাকএন্ডের `/auth/login` এন্ডপয়েন্টের সাথে কানেক্ট করে টোকেন ম্যানেজ করবে।
- তুমি যেহেতু শুধু একজন ইউজার হিসেবে থাকবে, তাই কনফিগারেশন সিম্পল রাখো।
- ব্যাকএন্ডে কুকি চেক করার লজিক (`req.cookies.token`) বাদ দাও, কারণ তুমি টোকেন হেডারে পাঠাচ্ছ।
- যদি কোনো নির্দিষ্ট এরর বা সমস্যা হয়, সেটা শেয়ার করো। আমি সেটা ফিক্স করে দেব।

তুমি চাইলে আমি একটা সম্পূর্ণ লগইন ফ্লোর কোড (ফ্রন্টএন্ড + ব্যাকএন্ড) দিতে পারি বা তোমার `create.ts` ফাইলের সাথে `next-auth` ইন্টিগ্রেশন করে দিতে পারি। জানাও কী চাও!
